## 1. この画面の役割

1枚のカード(タスク)の全情報を見て、編集する。担当者・期限・準備の手順を決める中心の画面。

## 2. 画面イメージ

ボード画面からカードを押すと、画面全体に開く。縦にスクロールする。

## 3. 部品の仕様

### ① ヘッダー
| 部品 | 動作 |
|---|---|
| ← 戻る | ボード画面へ戻る。入力内容は自動で保存済み |
| ⋯ メニュー | 「アーカイブ」「削除」 |

削除: 確認なしで削除し、画面下に「削除しました [元に戻す]」を10秒間表示する。削除したカードは30日間復元できる(N-09)。

### ② タイトル
- 押すと編集欄になる。最大100文字。
- 空にして確定はできない。「タイトルを入力してください」と表示し、元の文字に戻す。
- 下に「ボード名 › リスト名 [変更]」を表示する。「変更」を押すとリストの一覧が出て、選ぶと移動できる(長押し移動が苦手な人向け)。

### ③ 完了ボタン
| 状態 | 表示 | 押すと |
|---|---|---|
| 未完了 | ○ 完了にする | 完了にする。ボード画面の完了マークと同じ動作(演出、「完了」リストへ移動、完了日時の記録) |
| 完了済み | ✔ 完了(10/24 15:30・期限内) | 未完了に戻す。完了前のリストへ戻す |

- 未完了のチェック項目が残っていれば、確認を出す(UC-04)。

### ④ 担当者(F-30〜F-33)
- 表示は 👤 と名前。未設定は「⚠ 担当者なし」を橙色で表示する。
- 押すと、画面下から選択シートが出る。

```
┌────────────────────────┐
│ 担当者を選ぶ            │
│ ● 自分                  │
│ ○ 田中さん              │
│ ○ 佐藤さん              │
│ ○ 担当者なし            │
│ ─────────────────────  │
│ 新しい依頼先を入力      │
│ [ 名前          ] [追加]│
└────────────────────────┘
```

| 操作 | 動作 |
|---|---|
| 候補を選ぶ | 担当者にする。シートを閉じる |
| 名前を入力して「追加」 | 依頼先として登録し、そのまま担当者にする。次回から候補に出る |
| 「担当者なし」 | 担当者を外す(警告表示になる) |

- 入力できる名前は最大30文字。空白だけは追加できない。
- 同じ名前がすでにあるときは、新しく作らず既存の人を選ぶ。
- 依頼先には通知は届かない。選択シートの下に「依頼先には通知されません」と小さく表示する。
- 候補の名前の変更・削除は、設定画面で行う(今回は仕様外)。

### ⑤ 期限(F-20, F-21)
- 表示は、状態アイコン + 日時 + 状態の文字(ボード画面の §4 と同じ基準)。期限なしは「期限を設定」と表示する。
- 押すと、日付と時刻の選択シートが出る。

| 部品 | 動作 |
|---|---|
| クイック選択 | 「今日」「明日」「来週」を押すと日付が入る。時刻の初期値は設定の「期限の初期時刻」(初期値 18:00) |
| 日付・時刻 | スマホ標準の選択部品を使う |
| 「期限を消す」 | 期限をなしにする。通知の予定も消す |
| 「決定」 | 保存する |

- 過去の日時を選ぶと「過去の日時です。このままにしますか」と確認する。
- 期限を変えたら、通知の時刻を計算し直す。変更は履歴に残す(F-25)。

### ⑥ 通知(F-22)
- 期限があるときだけ設定できる。期限なしのときは灰色にして「期限を設定すると選べます」と表示する。
- 押すと、複数選択のシートが出る。

| 選択肢 | 通知する時刻 |
|---|---|
| 前日 | 期限の前日の「朝の通知時刻」(初期値 9:00) |
| 当日朝 | 期限の当日の「朝の通知時刻」(初期値 9:00) |
| 1時間前 | 期限の1時間前 |

- 「朝の通知時刻」は設定画面で変えられる(S-06)。
- 期限を設定したときの初期選択は「前日」と「1時間前」。
- すでに過ぎた時刻の通知は作らない(例: 期限が今日の10時で、今が9時半なら「当日朝」は選べない)。
- 期限を過ぎて未完了のときは、設定に関係なく超過の通知を1回送る(F-23)。
- 通知しない時間帯(F-61)に当たる場合は、時間帯の終了後に送る。

### ⑦ カレンダーに追加(F-80, UC-06)
- ボタンを押すと、期限をスマホのカレンダーへ登録する確認画面を開く。
- カレンダーに渡す内容:

| 項目 | 内容 |
|---|---|
| 予定名 | カードのタイトル |
| 日時 | 期限の日時から30分間(案) |
| 説明 | 担当者名と、カードの説明の冒頭 |

- 期限が未設定のとき、ボタンは灰色で押せない。「期限を設定すると使えます」と表示する。
- 登録後に期限を変えても、カレンダー側は自動では変わらない。期限を変えたとき、ボタンの下に「カレンダーの予定は変わりません。追加し直してください」と小さく表示する。
- iPhone ではカレンダーの追加画面が開く。Android では機種により、ファイルを開くアプリを選ぶ画面が出る。

### ⑧ チェックリスト(準備の手順)(F-40〜F-44)
| 操作 | 動作 |
|---|---|
| 項目の ☐ を押す | 完了にする / 戻す。見出しの「☑ 3/5」と進捗バーが更新される |
| 項目の文字を押す | 編集する(最大100文字) |
| 「＋ 手順を追加」 | 入力欄が開く。決定すると次の入力欄が続けて開き、まとめて入れられる |
| 項目を長押しして動かす | 並び替え |
| 項目を左へスワイプ | 削除ボタンを表示。確認なしで削除し、「元に戻す」を5秒間表示 |
| 「雛形から入れる」(推奨) | 保存してある雛形を選ぶ。選ぶと項目が追加される(既存の項目は残す) |
| 「雛形として保存」(推奨) | ⋯ にまとめる。いまの項目を雛形にする |

- 項目が0件のとき、進捗バーは出さず「手順を入れると進み具合がわかります」と表示する。
- 全項目が完了になっても、カードは自動では完了にしない。「全て完了しました。カードも完了にしますか [完了にする]」を表示する。
- 項目ごとの期限(F-41)は推奨。入れる場合は、項目の右に小さく日付を表示する。

### ⑨ 説明
- 押すと編集欄になる。最大2000文字。改行できる。
- 空のときは「説明を追加」と灰色で表示する。

### ⑩ ラベル(推奨, F-14)
- 色付きの帯 + 名称で表示する(色だけに頼らない)。
- 「＋」を押すと、既存のラベルを選ぶ、または新しい名称と色を決めて作る。

### ⑪ メモ(推奨, F-15)
- 日付つきで新しい順に表示する。「＋ メモを追加」で入力欄が開く。
- 自分のメモの編集・削除ができる。

### ⑫ 履歴(推奨, F-25, F-43)
- 初期は閉じておき、押すと開く。
- 表示する出来事: 作成 / リスト移動 / 期限変更 / 担当者変更 / 完了 / 完了の取り消し。
- 例: 「10/24 15:30 期限を 10/25 18:00 から 10/27 18:00 に変更」。
- 履歴は編集・削除できない。
- 担当者の変更を履歴に残すため、ER図の `card_events` の `event_type` に「担当者変更」を加える。

## 4. 保存のしかた
- 入力欄を閉じたとき、またはシートで「決定」を押したときに、自動で保存する。「保存」ボタンは置かない。
- 保存中は小さく「保存中…」、完了で「保存しました」を2秒表示する。
- 保存に失敗したら、入力内容を残したまま「保存できませんでした [もう一度試す]」を表示する。
- オフライン中は端末に保存し、復帰後に反映する。

## 5. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | 各項目の形をした灰色の枠(スケルトン) |
| 読み込み失敗 | 「読み込めませんでした」+「もう一度試す」 |
| 他の端末で削除済み | 「このカードは削除されました」+ ボード画面へ戻るボタン |
| 完了済みのカード | 全項目を表示。編集はできる。タイトルに取り消し線は付けない(読みにくいため)。③に完了日時を表示 |

## 6. 見やすさ・操作性
- 押せる部品は 44×44px 以上。項目と項目の間は十分にあける(誤タップ防止)。
- 文字は 16px 以上。設定の文字サイズに従う。
- 入力欄を開いたとき、キーボードに隠れないよう画面を自動でずらす。
- 主要操作(担当者の変更、期限の変更、手順の完了)は、この画面から2〜3タップで行える。

## 7. この画面で使うデータ
[ER図](er-diagram.md) の `cards` `assignees` `checklist_items` `card_reminders` `card_labels` `labels` `card_comments` `card_events` `checklist_templates` `template_items`。
