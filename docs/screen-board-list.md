## 1. この画面の役割

自分のボードを一覧し、開きたいボードを選ぶ。ボードの作成・名称変更・アーカイブもここで行う。ログイン後に最初に開く画面。

## 3. 部品の仕様

### ① ヘッダー
- 「ボード」と表示する。戻るボタンはない(ログイン後の最初の画面のため)。
- 右の ⇅ を押すと、並び順を選ぶシートが出る。

| 並び順 | 内容 |
|---|---|
| 最近開いた順(初期値) | 最後に開いた日時が新しい順。自動で並ぶ |
| 手で並べた順 | 自分で決めた順。長押しして上下にドラッグして並び替える |

- 選んだ並び順は設定に保存し、次回も同じにする(`user_settings.board_sort`)。
- 「手で並べた順」のとき、ボードのカードに ≡ の持ち手を表示する。持ち手を長押しして動かすと並び替わり、指を離すと保存する。
- 「最近開いた順」のときは持ち手を出さない。並び替えようとして長押ししたときは「手で並べた順に切り替えると並び替えできます [切り替える]」と案内する。
- 「手で並べた順」でボードを新しく作ると、一番上に入る。アーカイブから戻したボードは一番上に入る。
- 手で並べた順は、「最近開いた順」に切り替えても消さずに残す。

### ② 警告バナー
ボード画面(S-03)と同じ条件・文言で表示する。

### ③ ボードのカード
1つのボードを1枚のカードで表す。

| 項目 | 表示内容 | 備考 |
|---|---|---|
| ボード名 | 1行。長いときは「…」 | 最大30文字 |
| 未完了の件数 | 「未完了 7件」 | アーカイブ済みのカードと完了済みのカードは数えない |
| 超過の件数 | 「❗超過 2件」 | 0件なら表示しない |
| もうすぐの件数 | 「⏰もうすぐ 1件」 | 0件なら表示しない。基準は設定の `due_soon_hours`(初期24時間) |
| ⋯ メニュー | 「名称を変更」「アーカイブ」 | 右上。44×44px 以上 |

| 操作 | 動作 |
|---|---|
| カードを押す | そのボードのボード画面(S-03)を開く。`last_opened_at` を更新する |
| ⋯ を押す | メニューを表示する |

- 件数は色だけでなく、アイコンと文字で示す(N-11)。
- 並び順は ① で選んだ方式に従う。

### ③-a 名称を変更
- 画面下から入力シートが出る。現在の名前が入っている。
- 1〜30文字。空や空白だけは「名前を入力してください」と表示して確定できない。
- 同じ名前のボードがあってもよい(区別は利用者に任せる)。

### ③-b アーカイブ
- 押すと確認を出す。「『仕事ボード』をアーカイブしますか。カードは残り、あとで戻せます」。ボタンは「アーカイブする」「やめる」。
- アーカイブしたボードは、次のように扱う。

| 項目 | 扱い |
|---|---|
| 一覧 | 通常の一覧から消え、⑤の「アーカイブ済み」に移る |
| 通知 | そのボードのカードの通知(期限前・超過)は送らない |
| 「自分のタスク」 | そのボードのカードは表示しない |
| 実績 | これまでの完了実績は残して数える |
| 復元 | 「アーカイブ済み」から戻すと、通知と表示が元に戻る。期限を過ぎていた通知は送らない |

- アーカイブの直後に画面下へ「アーカイブしました [元に戻す]」を5秒間表示する。

### ④ ボードを作る
- 押すと、画面下から入力シートが出る。
- 入力: ボード名(必須。1〜30文字)。
- 「作成」を押すと、初期リスト4つ(未着手 / 進行中 / レビュー / 完了)を持つボードを作り、そのままボード画面(S-03)を開く。
- 作れるボードは、アーカイブ済みを除いて20個まで。超えたときは「ボードは20個までです。使わないボードをアーカイブしてください」と表示し、ボタンを押せなくする。

### ⑤ アーカイブ済み
- 件数つきで、折りたたんで表示する。押すと開く。0件のときは表示しない。
- 開くと、アーカイブ済みのボード名と、右に「元に戻す」ボタンを並べる。
- アーカイブ済みのボードは、押しても中身を開けない(先に「元に戻す」が必要)。
- ボードの完全な削除は、この画面では行わない(誤って消さないため。将来の検討)。

### ⑥ 下のメニュー
ボード / 自分のタスク / 実績 / 設定。現在地は「ボード」。色と下線で示す。

## 4. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | ボードのカードの形をした灰色の枠(スケルトン)を3つ表示 |
| ボードが0件(全てアーカイブ済みなど) | 「ボードがありません。最初のボードを作りましょう」+ ④を強調 |
| 読み込み失敗 | 「読み込めませんでした」+「もう一度試す」ボタン |
| 保存失敗(作成・名称変更・アーカイブ) | 変更を元に戻し、「保存できませんでした」と短く表示 |
| オフライン | ②のバナーを表示。最後に読み込んだ内容を表示する。作成・名称変更・アーカイブは端末に保存し、復帰後に反映する |

## 5. 見やすさ・操作性
- ボードのカードは1列で縦に並べる。1枚の高さは 72px 以上、カード同士の間隔は 12px 以上。
- 文字は 16px 以上。設定の文字サイズに従う。拡大するとカードの高さも伸びる。
- 主要操作(ボードを開く、作る)は1〜2タップ。
- 長い一覧は縦にスクロールする。下の「ボードを作る」は、一覧の最後に置く(画面に固定しない)。

## 6. この画面で使うデータ
[ER図](er-diagram.md) の `boards`(`name` `archived` `position` `last_opened_at`)、`lists`、`cards`(件数の集計に `due_at` `completed_at` `archived` `deleted_at`)、`user_settings`(`board_sort`)。
