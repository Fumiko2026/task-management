# 画面仕様 3: ログイン / 会員登録

| 項目 | 内容 |
|---|---|
| 画面ID | S-01(ログイン)、S-01a(会員登録)、S-01b(パスワード再設定) |
| 関連要件 | F-01, F-02 / N-07, N-12 |
| 想定画面幅 | スマートフォン縦向き(幅 360〜430px) |
| 状態 | 初版(版 0.1) |

## 1. この画面の役割

利用者を確認し、その人のデータだけを見せる入口。初めての人は会員登録、2回目以降はログインする。

## 2. 画面の構成

| 画面 | 内容 |
|---|---|
| S-01 ログイン | メールアドレスとパスワードで入る |
| S-01a 会員登録 | 初めて使う人がアカウントを作る |
| S-01b パスワード再設定 | パスワードを忘れたときに作り直す |

## 3. S-01 ログイン

### 画面イメージ
```
┌──────────────────────────────┐
│                              │
│        task-management       │
│    やることを、確実に。       │
│                              │
│ メールアドレス               │
│ [                          ] │
│ パスワード                   │
│ [                    👁   ] │
│                              │
│ ☑ ログイン状態を保つ         │
│                              │
│ [        ログイン          ] │
│                              │
│  パスワードを忘れた方        │
│ ──────────────────────────  │
│  はじめての方は 会員登録     │
└──────────────────────────────┘
```

### 部品の仕様
| 部品 | 動作 |
|---|---|
| メールアドレス | 入力欄。スマホでは「@」入りのキーボードを出す。前後の空白は無視する |
| パスワード | 入力欄。初期は伏せ字。👁 を押すと表示 / 非表示を切り替える |
| ログイン状態を保つ | 初期はオン。オンなら30日間は再入力なしで開く。共用の端末ではオフにする |
| ログイン | 押すと認証する。成功したらボード一覧(S-02)へ。通信中はボタンを押せなくし「確認中…」と表示する |
| パスワードを忘れた方 | S-01b へ |
| 会員登録 | S-01a へ |

### エラー表示
| 状況 | 表示 |
|---|---|
| 未入力 | 欄の下に「メールアドレスを入力してください」「パスワードを入力してください」 |
| メールの形が違う | 「メールアドレスの形式が正しくありません」 |
| 認証に失敗 | 「メールアドレスまたはパスワードが違います」 |
| 連続で5回失敗 | 「しばらくしてからお試しください(10分後)」。入力欄は触れる。ログインボタンを押せなくする |
| 通信できない | 「通信できません。電波の良い場所でお試しください」 |

- 認証に失敗したとき、メールとパスワードのどちらが違うかは教えない(他人にメールの登録有無を知られないため)。

## 4. S-01a 会員登録

### 画面イメージ
```
┌──────────────────────────────┐
│ ←  会員登録                  │
│                              │
│ 表示名(担当者欄に出ます)   │
│ [                          ] │
│ メールアドレス               │
│ [                          ] │
│ パスワード(8文字以上)      │
│ [                    👁   ] │
│  ✔ 8文字以上                │
│  ✔ 英字と数字を含む         │
│                              │
│ ☐ 利用規約とプライバシー     │
│   ポリシーに同意する         │
│                              │
│ [        登録する          ] │
└──────────────────────────────┘
```

### 入力項目
| 項目 | 規則 |
|---|---|
| 表示名 | 必須。1〜30文字。担当者の「自分」として表示される |
| メールアドレス | 必須。メールの形式。すでに登録済みのものは使えない |
| パスワード | 必須。8文字以上で、英字と数字を両方含む。入力中に条件を満たすたび ✔ を付ける |
| 同意 | チェックしないと「登録する」を押せない。規約とポリシーの文字を押すと内容を開く |

### 登録後の流れ
1. 確認メールを送る。画面に「○○に確認メールを送りました。メールのリンクを押して登録を完了してください」と表示する。
2. 利用者がメールのリンクを押す(24時間以内)。
3. 登録が完了し、ボード一覧へ進む。
4. 同時に、次を自動で作る。
   - `user_settings`(初期値)
   - `assignees` に本人の行(`is_self` が真、名前は表示名)
   - 最初のボード「はじめてのボード」と、初期リスト4つ(未着手 / 進行中 / レビュー / 完了)

### エラー表示
| 状況 | 表示 |
|---|---|
| すでに登録済みのメール | 「このメールアドレスは登録できません。ログインまたはパスワード再設定をお試しください」 |
| パスワードが条件を満たさない | 条件の項目を赤字とアイコン(✖)で示す |
| 確認メールのリンクが期限切れ | 「リンクの期限が切れました」+「確認メールを再送する」ボタン |

## 5. S-01b パスワード再設定(F-02)

### 流れ
1. ログイン画面の「パスワードを忘れた方」を押す。
2. メールアドレスを入力して「再設定メールを送る」を押す。
3. 画面に「入力されたアドレスが登録されていれば、再設定のメールを送りました」と表示する。登録の有無にかかわらず同じ文言にする。
4. メールのリンク(1時間有効・1回のみ有効)を押すと、新しいパスワードの入力画面が開く。
5. 新しいパスワードを2回入力して「変更する」を押す。成功したらログイン画面へ戻り「パスワードを変更しました」と表示する。

### 規則
- 新しいパスワードの条件は会員登録と同じ。
- 2回の入力が違うときは「パスワードが一致しません」。
- リンクの期限切れや使用済みのときは「リンクが無効です。もう一度お試しください」と表示し、再設定メールの送信画面へ戻る。
- パスワードを変えたら、他の端末のログイン状態を全て解除する。

## 6. ログアウト
- 設定画面(S-06)の一番下に「ログアウト」を置く。
- 押すと確認を出さずにログアウトし、ログイン画面へ戻る。端末に残るログイン情報は消す。
- オフライン中でもログアウトできる。

## 7. 初回の案内(ログイン直後)
| タイミング | 内容 |
|---|---|
| 初めてログインしたとき | 「ホーム画面に追加すると、アプリのように使えます」と案内する。iPhone は共有ボタンから「ホーム画面に追加」の手順を絵つきで出す。「あとで」で閉じられる |
| 初めて期限を設定したとき | 「期限をお知らせするため、通知を許可してください」と理由を説明してから、OSの許可画面を出す(最初から出すと断られやすいため) |

- iPhone では、ホーム画面に追加していないと通知は使えない(N-01)。通知を許可する前に、この条件を案内する。

## 8. 安全面(N-07, N-12)
- 通信は暗号化する(TLS)。
- パスワードは元に戻せない形(ハッシュ)で保存する。画面にもログにも出さない。
- パスワード欄には端末のパスワード管理機能が使えるよう、入力欄の種類を正しく指定する。
- 取得する情報は、表示名とメールアドレスだけ(N-12)。
- 退会(アカウントとデータの全削除)は設定画面に置く(別途仕様を書く)。

## 9. 見やすさ・操作性
- 入力欄の高さは 48px 以上。押せる部品は 44×44px 以上。
- 入力欄にはラベルを常に表示する(入力を始めても消えない)。
- エラーは、色だけでなくアイコンと文字で示す。
- 入力欄にエラーがあるときは、最初のエラー欄にカーソルを移す。
