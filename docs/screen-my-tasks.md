## 1. この画面の役割

全てのボードのカードを、期限が近い順に並べて見る。「今日、何からやるか」を決める画面。人に頼んだ件(依頼中)の確認にも使う。

## 2. 画面イメージ

├──────────────────────────────┤

## 3. 部品の仕様

### ① ヘッダー
| 部品 | 動作 |
|---|---|
| タイトル | 「自分のタスク」 |
| ボードの絞り込み | 「全ボード」を押すと、ボード名の一覧が出る。1つ選ぶとそのボードのカードだけを表示。初期値は全ボード |

- アーカイブしたボードは選択肢に出さず、そのカードも表示しない(ボード一覧 S-02 の決定による)。

### ② 切り替え
3つの切り替えを横に並べる。選んだ切り替えは、色と下線で示す。

| 切り替え | 表示するカード |
|---|---|
| 自分(初期) | 担当者が自分で、未完了のカード |
| 依頼中 | 担当者が依頼先(自分以外)で、未完了のカード |
| 全て | 担当者なしを含む、未完了のカード全て |

- 切り替えの名前の横に、件数を表示する(例: 「自分 6」)。
- 「依頼中」を選んだときは、一覧の上に依頼先の名前を横に並べる。名前を押すとその人だけに絞り込む(F-34, UC-09)。「全員」で戻る。名前が多いときは横にスクロールする。

### ③ お知らせ
- 担当者のないカードがあるときだけ、「自分」の切り替えの一番上に「⚠ 担当者のないカードが 3件」を表示する(F-31)。
- 「見る」を押すと「全て」に切り替え、担当者のないカードだけに絞り込む。絞り込み中は「担当者なしのみ表示中 [解除]」と出す。
- 担当者のないカードは、「全て」では「⚠ 担当者なし」を橙色で表示する。

### ④ 期限ごとのまとまり
カードを、期限の状態ごとのまとまりに分けて並べる。まとまりの見出しに件数を表示する。0件のまとまりは表示しない。

| まとまり | 条件(日本時間) |
|---|---|
| ❗ 超過 | 期限を過ぎて未完了 |
| 今日 | 期限が今日 |
| 明日 | 期限が明日 |
| 今週 | 明後日から今週の日曜まで(週は月曜はじまり) |
| それ以降 | 来週以降 |
| 期限なし | 期限が未設定 |

- 並び順: まとまりは上の順。まとまりの中は、期限が近い順(期限が同じなら、作成が古い順)。
- 「超過」だけは、期限が古い順(いちばん遅れているものが一番上)。
- 見出しを押すと、そのまとまりを折りたためる。「超過」は折りたたむときに確認なしで閉じられるが、見出しに件数が残るため気づける。

### ④-a カードの行
| 項目 | 表示内容 | 備考 |
|---|---|---|
| 完了マーク | 左の ○ | タップで完了にする(§3-④-b) |
| タイトル | 最大2行。超えたら「…」 | |
| 場所 | 「ボード名 › リスト名」 | 1行。長いときは「…」 |
| 担当者 | 👤 と名前 | 「自分」の切り替えでは省略。「依頼中」「全て」で表示 |
| 期限 | 状態アイコン + 日時 + 状態の文字 | ボード画面 §4 と同じ基準。日時は「今日 15:00」のように、まとまりに合わせて短くする |
| チェックリスト | ☑ 完了数/全体数 | 項目が0件なら非表示 |

### ④-b 操作
| 操作 | 動作 |
|---|---|
| 行を押す(○以外) | カード詳細(S-04)を開く。戻ると、この画面の同じ位置に戻る |
| ○ を押す | 完了にする。ボード画面の完了マークと同じ動作(演出、「完了」リストへの移動、完了日時の記録)。行は一覧から消える。画面下に「完了にしました [元に戻す]」を5秒間表示する |
| 未完了のチェック項目がある場合 | 「チェックリストが残っています。完了にしますか」と確認する |
| 下に引っ張る | 最新の状態に更新する |

- ○ のタップできる範囲は 44×44px 以上。
- 並び替えはできない(期限の順に自動で並ぶため)。順番を変えたいときは、カード詳細で期限を変える。

### ⑤ 完了の表示
- 「完了したものも表示」をオンにすると、一覧の一番下に「完了(直近30日)」のまとまりを出す。完了日時が新しい順。
- 完了のカードは ✔ と「完了」の文字を緑で表示する。✔ を押すと、未完了に戻す(元のリストへ戻る)。
- 初期はオフ。選択は端末に保存する。

### ⑥ 下のメニュー
ボード / 自分のタスク / 実績 / 設定。現在地は「自分のタスク」。
- 「自分のタスク」の項目に、超過の件数を数字の丸(例: ❗1)で表示する。0件のときは表示しない。色だけでなく数字で示す(N-11)。

## 4. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | 行の形をした灰色の枠(スケルトン)を表示 |
| 「自分」が0件 | 「予定はありません。ゆっくり過ごしましょう」(UC-02) |
| 「依頼中」が0件 | 「依頼中のタスクはありません」 |
| 「全て」が0件 | 「タスクがありません。ボードでカードを追加しましょう」+ ボードへ移るボタン |
| 絞り込みで0件 | 「条件に合うタスクはありません」+「絞り込みを解除」 |
| 読み込み失敗 | 「読み込めませんでした」+「もう一度試す」 |
| 保存失敗(完了にしたとき) | 行を元の位置に戻し、「保存できませんでした」と短く表示 |
| オフライン | 画面上部に「通信できません。編集は後で反映されます」を表示。最後に読み込んだ内容を表示し、完了などの操作は端末に保存して復帰後に反映する |

## 5. 見やすさ・操作性
- 行の高さは 72px 以上。行どうしの間隔は 8px 以上。
- 見出しは、縦にスクロールしても画面上部に残す(いま見ているまとまりがわかる)。
- 文字は 16px 以上。設定の文字サイズに従う。
- 主要操作(完了にする、カードを開く)は1タップ。
- 期限の状態は、色だけでなくアイコンと文字でも示す(N-11)。

## 6. この画面で使うデータ
[ER図](er-diagram.md) の `cards`(`due_at` `completed_at` `archived` `deleted_at`)、`lists`、`boards`、`assignees`(`is_self`)、`checklist_items`、`card_events`(完了前のリストの記録)。

- 取得条件: 自分のユーザーID、`boards.archived` が偽、`cards.archived` が偽、`cards.deleted_at` が空。
