## 1. この画面の役割

「期限を守って仕事を終えている」ことを、数字と記録で確かめる。自分の仕事ぶりを振り返り、自信につなげる。見るのは本人だけ(F-75)。

## 2. 画面の考え方

- **控えめな表現にする。** 派手な演出や、子供向けのほめ言葉は使わない。数字と事実を静かに示す。
- **事実だけを示す。** 率が低い月も、責める言葉を使わない。何件が期限内で、何件が超過だったかを、そのまま見せる。
- **あとから数字を作れないようにする。** 期限内かどうかは、完了にした時点で判定して保存する(ER図の `completed_on_time`)。完了したあとに期限を変えても、過去の実績は変わらない。

## 4. 部品の仕様

### ① ヘッダー
- 「実績」と表示する。

### ② 月の切り替え
| 部品 | 動作 |
|---|---|
| ◀ | 前の月を表示する |
| ▶ | 次の月を表示する。今月のときは押せない(灰色) |
| 月の表示 | 「2026年10月」。押すと、月を選ぶシートを出す(記録がある月だけ) |

- 初期は今月。月は日本時間で区切る。
- 最初に完了の記録がある月より前には戻れない。

### ③ 期限内完了率 (F-72)

#### 数え方
| 項目 | 内容 |
|---|---|
| 対象 | その月に完了にしたカードのうち、完了にした時点で期限が設定されていたもの |
| 期限内 | 完了日時が、期限の日時以前のもの |
| 超過 | 完了日時が、期限の日時より後のもの |
| 率 | 期限内の件数 ÷ 対象の件数。小数点以下は四捨五入して整数にする |
| 期限なしで完了 | 率には含めず、別の行で件数だけを示す |

- 完了を取り消したカードは、数に入れない。もう一度完了にしたときは、そのときの日時で数え直す。
- アーカイブしたボードやカードの完了も数える。ごみ箱のカードと、完全に削除したカードは数えない。

#### 表示
| 項目 | 内容 |
|---|---|
| 率 | 大きな数字で「92%」 |
| 内訳 | 「期限つきで完了 25件のうち ✔ 期限内 23件 ❗超過 2件」 |
| 前月との比較 | 「前の月より ▲ 4ポイント」「前の月と同じ」「前の月より ▼ 3ポイント」。矢印と文字で示す(色だけに頼らない)。前の月に対象がなければ表示しない |
| 期限なしで完了 | 「期限なしで完了 3件」。0件なら表示しない |
| ひとこと | 率に合わせて短い文を1行だけ添える(下表) |

| 率 | ひとこと |
|---|---|
| 100% | この月は、すべて期限内に終えました |
| 90〜99% | この月は、期限をしっかり守れています |
| 70〜89% | 多くのタスクを期限内に終えています |
| 50〜69% | 期限内に終えたタスクが、半数を超えています |
| 49%以下 | 超過したタスクは、履歴で確認できます |
| 対象が0件 | (ひとことは出さない) |

- 今月以外の月を見ているときは、文頭を「この月は」にする(今月は「今月は」)。
- 率の基準は、日本語の言い回しとあわせて、実際に使いながら見直す。

- 率は、色の濃淡の差をつけすぎず、落ち着いた1色で表示する。

#### 対象が0件のとき
- 率の位置に「—」を表示し、「期限つきで完了したタスクが、まだありません」と書く。

### ④ 月ごとの推移
- 期間を「3か月」「6か月」「1年」の3つから選べる。選んだ期間は端末に保存する。初期は「6か月」。
- 期間は、② で表示している月を最後にした「直近○か月」とする(1年は12か月)。例: 2026年10月を表示中に「3か月」を選ぶと、8月・9月・10月を並べる。
- 各月の率を、横向きの棒と数字で並べる。数字を必ず添える(棒の長さだけに頼らない)。月は古い順に上から並べる。
- 表示している月は、太字で強調する。
- 対象が0件の月は、棒を出さず「—」と書く。
- 最初に完了の記録がある月より前の月は、並べない(例: 記録が2か月分のとき、「1年」を選んでも2か月分だけ表示する)。
- 「1年」は12行になるため、推移の部分だけを縦にスクロールさせず、画面全体のスクロールで見る。
- 棒を押しても、何も起きない(月を切り替えるには ② を使う)。
- 期間の見出しの下に、期間の平均を1行で示す(例: 「6か月の平均 87%」)。平均は、期間内の全ての月の期限内の件数の合計 ÷ 対象の件数の合計で求める(月ごとの率の平均ではない)。

### ⑤ 完了の履歴 (F-74)

#### 一覧
| 項目 | 内容 |
|---|---|
| 範囲 | ② で選んだ月に完了したカード |
| 並び順 | 完了日時が新しい順。日ごとに見出し(例: 「10/26(日)」)をつける |
| 絞り込み | 「すべて」「期限内」「超過」から選ぶ。初期は「すべて」 |
| 行の内容 | ✔ タイトル / 期限の結果(下表)/ ボード名 / 完了した時刻 |
| 件数 | 最初に30件。「もっと見る」で、30件ずつ足す |

| 期限の結果 | 表示 |
|---|---|
| 期限内 | ✔ 期限内(緑) |
| 超過して完了 | ❗ 超過(赤) |
| 期限なし | 表示しない |

- 色だけでなく、アイコンと文字で示す(N-11)。

#### 操作
| 操作 | 動作 |
|---|---|
| 行を押す | カード詳細(S-04)を開く。戻ると、この画面の同じ位置に戻る |
| 行が「ごみ箱」のカード | 一覧に出さない |
| カードが完全に削除された場合 | 一覧に出さない |

### ⑥ 下のメニュー
ボード / 自分のタスク / 実績 / 設定。現在地は「実績」。

## 5. 完了したときの演出との関係 (F-70)

- カードを完了にしたときの演出(チェックマークのアニメーションと振動)は、ボード画面・自分のタスク・カード詳細で行う。この画面では行わない。
- 演出は、設定画面の「完了の演出」でオフにできる(S-06b)。

## 7. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | 数字・棒・行の形をした灰色の枠(スケルトン) |
| 完了の記録が1件もない | 「まだ記録がありません。タスクを完了にすると、ここに記録されます」(UC-07) |
| 選んだ月に完了がない | 「この月に完了したタスクはありません」 |
| 読み込み失敗 | 「読み込めませんでした」+「もう一度試す」 |
| オフライン | 画面上部に「通信できません」を表示。最後に読み込んだ内容を見せる。オフラインで完了にした分は、復帰後に反映されるまで数に入らない旨を、小さく添える |

## 8. 見やすさ・操作性
- 率の数字は 40px 以上。設定の文字サイズに従って大きくなる。
- 履歴の行の高さは 64px 以上。
- 本文の文字は 16px 以上。
- 月の切り替えの ◀ ▶ は 44×44px 以上。
- 推移は、棒と数字の両方で示す。

## 9. プライバシー (F-75, N-07)
- 実績は、本人のログイン中にだけ見られる。
- 他の人に見せたり、通知したりしない。
- 退会すると、実績は全て削除する。

## 10. この画面で使うデータ
[ER図](er-diagram.md) の `cards`(`completed_at` `due_at` `completed_on_time` `deleted_at`)、`lists`、`boards`、`card_events`。

- 月ごとの集計は、`completed_at` を日本時間で月に分けて数える。
