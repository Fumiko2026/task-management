## 決定事項

| No. | 内容 | 決定 |
|---|---|---|
| 1 | 「もうすぐ」の基準 | 期限の24時間前 |
| 2 | リストの見せ方 | 複数のリストを横に並べて見せる |

## 1. この画面の役割

1つのボードの中身(リストとカード)を見渡し、カードを動かして進み具合を管理する。

## 2. 画面イメージ

2つのリストが同時に見え、右端に次のリストが少しのぞく。

```
┌──────────────────────────────────┐
│ ←  仕事ボード            🔍  ⋯   │  ① ヘッダー
├──────────────────────────────────┤
│ ⚠ 通知がオフです。設定する        │  ② 警告バナー(必要なときだけ)
├──────────────────────────────────┤
│ 未着手 2        │ 進行中 1      │ 進  ③ リスト見出し
│ ┌────────────┐ │ ┌────────────┐│ 行
│ │○ 見積書を  │ │ │✔ 契約書の  ││
│ │  作る      │ │ │  確認      ││
│ │👤 自分     │ │ │👤 田中さん ││
│ │❗10/25 超過│ │ │✔ 完了      ││
│ │☑ 3/5 ▓▓▓░░ │ │ └────────────┘│
│ └────────────┘ │ ┌────────────┐│
│ ┌────────────┐ │ │○ 資料を送る││
│ │○ 資料を    │ │ │👤 自分     ││
│ │  まとめる  │ │ │⏰10/28     ││
│ │⚠ 担当者なし│ │ └────────────┘│
│ └────────────┘ │               │
│ ＋ カードを追加 │ ＋ カードを追加│  ⑤ カード追加
├──────────────────────────────────┤
│ ボード   タスク   実績   設定    │  ⑥ 下のメニュー
└──────────────────────────────────┘
```

## 3. 部品の仕様

### ① ヘッダー
| 部品 | 動作 |
|---|---|
| ← 戻る | ボード一覧(S-02)へ戻る |
| ボード名 | 表示のみ。長いときは末尾を「…」で省略 |
| 🔍 検索 | 押すと検索・絞り込み欄が開く(§5) |
| ⋯ メニュー | 「ボード名の変更」「リストを追加」「期限順に並べる」「アーカイブ」 |

### ② 警告バナー
次のときだけ、ヘッダーの下に表示する。

| 条件 | 文言 | 押すと |
|---|---|---|
| OSの通知が無効 | 通知がオフです。期限をお知らせできません | 通知の設定方法を表示 |
| オフライン | 通信できません。編集は後で反映されます | 閉じる |

### ③ リスト
- 初期リスト: 未着手 / 進行中 / レビュー / 完了。
- 1つのリストの幅は、画面幅の約45%(360px の画面で約160px)。2つのリストが並んで見え、右端に次のリストが少しのぞく。
- 横にスワイプして他のリストへ移る。リスト内は縦にスクロールする。見出しは縦スクロールしても上に残す。
- 見出しにカードの件数を表示する。
- 見出しを押すと「名称変更」「アーカイブ」を出す。見出しを長押しして左右にドラッグすると並び替え。
- 「完了」リストへ移したカードは、完了日時を記録する(UC-04)。

### ④ カード
幅が狭いため、情報を絞って表示する。詳しい内容はカード詳細(S-04)で見る。

| 項目 | 表示内容 | 備考 |
|---|---|---|
| 完了マーク | カード左上の ○ (完了済みは ✔) | §3-④-a |
| タイトル | 最大3行。超えたら「…」 | 必須項目 |
| 担当者 | 👤 と名前(長いときは「…」) | 未設定は「⚠ 担当者なし」を橙色で表示 |
| 期限 | 状態アイコン + 日付 + 状態の文字 | §4。幅が足りないときは日付を「10/25」の短い形にする |
| チェックリスト | ☑ 完了数/全体数 と進捗バー | 項目が0件なら非表示 |
| ラベル | 色付きの小さな帯(推奨機能) | 名称は詳細画面で見る |

#### ④-a 完了マーク(決定事項 3)
| 操作 | 動作 |
|---|---|
| ○ をタップ | 完了にする。チェックマークが描かれ、軽く振動する(演出がオンのとき)。カードを「完了」リストへ移し、完了日時を記録する |
| ✔ をタップ | 未完了に戻す。完了前にいたリストへ戻し、完了日時を消す |
| タップできる範囲 | カード左上の 44×44px 以上 |
| 押し間違えの対策 | 完了にした直後に画面下へ「完了にしました [元に戻す]」を5秒間表示する |
| 未完了のチェック項目がある場合 | 「チェックリストが残っています。完了にしますか」と確認する(UC-04) |

#### ④-b カードの操作
| 操作 | 動作 |
|---|---|
| 短く押す(○以外) | カード詳細(S-04)を開く |
| 長押し(約0.5秒) | 軽く浮き上がり振動。そのまま動かしてリスト間・リスト内を移動 |
| 左右の端へドラッグ | 隣のリストへ自動でスクロール |
| 指を離す | その位置に置く。位置を保存する |

### ⑤ カードを追加
- 押すとその場に入力欄が開く(別画面にしない)。
- タイトルだけ入れて「追加」を押せば作れる。担当者は自分、期限なしで作成。詳細はカード詳細で後から入れる。
- 空のまま「追加」は押せない。

### ⑥ 下のメニュー
ボード / 自分のタスク / 実績 / 設定。現在地の項目は色と下線で示す。

## 4. 期限の状態表示

色だけで伝えない(N-11)。必ずアイコンと文字を一緒に出す。

| 状態 | 条件 | アイコン | 文字 | 色 |
|---|---|---|---|---|
| 通常 | 期限まで24時間より先 | 🕒 | 日付のみ | 灰 |
| もうすぐ | 期限まで24時間以内 | ⏰ | 「もうすぐ」 | 黄 |
| 超過 | 期限を過ぎて未完了 | ❗ | 「超過」 | 赤 |
| 完了 | 完了済み | ✔ | 「完了」 | 緑 |
| 期限なし | 期限が未設定 | — | 表示しない | — |

基準の24時間は設定値 `user_settings.due_soon_hours` に持つ。初期値は24で、画面からの変更は将来対応とする。

## 5. 検索・絞り込み(F-17, F-34)

- 🔍 を押すと、ヘッダーの下に検索欄を出す。
- キーワード(タイトル・説明)で絞り込む。
- 条件の追加: 担当者 / 期限(今日・今週・超過) / ラベル。
- 絞り込み中は「3件を表示中」と出し、「解除」で元に戻す。
- 一致しないカードは隠し、リストの件数は一致した件数にする。

## 6. 並び順
- リスト内のカードは、手で並べた順を基本とする。
- 「期限順に並べる」を ⋯ メニューに用意する(押すと期限が近い順。期限なしは最後)。

## 7. 状態ごとの表示

| 状態 | 表示 |
|---|---|
| 読み込み中 | カードの形をした灰色の枠(スケルトン)を表示 |
| ボードにカードが0件 | 「最初のカードを追加しましょう」と案内 + ⑤を強調 |
| リストにカードが0件 | 「カードはありません」 |
| 読み込み失敗 | 「読み込めませんでした」+「もう一度試す」ボタン |
| 保存失敗 | カードを元の位置に戻し、「保存できませんでした」と短く表示 |
| オフライン | ②のバナーを表示。閲覧と編集は可能。復帰後に保存 |

## 8. 見やすさ・操作性
- 押せる部品の大きさは 44×44px 以上(N-02, N-13)。
- 文字の標準は 16px 以上。設定で拡大できる。リストの幅が狭いため、拡大すると改行が増える。極端に大きいとき(150%以上)は、リストを1つずつ見せる表示に自動で切り替える。
- 主要操作(カード追加・移動・完了)は3タップ以内。
- 移動は長押し以外にも、カード詳細の「リストを変更」で行える(長押しが苦手な人のため)。
- 文字と背景のコントラスト比は 4.5:1 以上。

## 9. この画面で使うデータ
[ER図](er-diagram.md) の `boards` `lists` `cards` `checklist_items` `assignees` `labels` `card_labels` `card_events`(完了前のリストの記録)。
